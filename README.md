# pagina-personal
Página web personal con información biográfica, asignaturas y horario académico.

## Descripción

Este proyecto presenta información personal y académica del estudiante, incluyendo datos biográficos, asignaturas inscritas, horario de clases e información de contacto.

## Tecnologías

- HTML5
- CSS3

## Estructura

- `index.html` — estructura y contenido de la página.
- `styles.css` — estilos y diseño visual.
- `Photos/` — imágenes utilizadas en la página.

## Publicación

El sitio web está publicado mediante GitHub Pages.
